# A2LtoECU
Simple python script and GUI for conversion of A2L file to .ECU file format. I found it particularly useful to convert and add to disassembled ME7 files in IDA pro usign the autoit scrips on nefmoto.  

Make sure A2L2ECU.py and A2L2ECU_v1.py are in the same folder. Double click A2L2ECU for a gui to pop open, add A2L and optionally add existing .ecu file if desired, or generate new from A2L.
Works with Python 3 and onwards i'd guess. I've tested with Python 3.11.15
